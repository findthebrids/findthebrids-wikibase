# Overview

![Brid in a Floatie](img/bridinafloatie.png) Brid in a Floatie is a Brid created by @Evanprice141 that was added on May 22, 2026, to replace Ocean Brid, a Brid created by @kajussls121 that was added on January 25, 2026.

# Obtainment

In the Desert area, floating on the surface of the water.

# Trivia

- This Brid's hint reads '*At the top of the sea.*' and its description reads '*Why cant he swimm :(((*'
- This Brid's original, Ocean Brid, is one of the first 25 Brids added to the game, being the twenty-fourth Brid.
