# Overview

![Lottery Brid](img/lotterybrid.png) Lottery Brid is a Brid created by @LazerAmplified that was added on January 19, 2026.

# Obtainment

On a tree in the ice area, there is a code: '*/e lottery*'. Entering this code will bring you to this Brid's subarea, where you then have to type '/e' and then a random number from 1 to 292,201,338 with commas. The correct number to type is '*/e 51,904,396*'.

# Trivia

- This Brid's hint reads '*GAMBLING 🤑🤑*' and its description reads '*I... My condolences.'
- This Brid is one of the first 25 Brids added to the game, being the thirteenth Brid.
- Before precise difficulty ratings were removed, this Brid had a difficulty of Impossible (777.77).
- This Brid is not required to be collected to complete the game. It is the first Brid to do so.
