# Overview

![Pizza Brid](img/pizzabrid.png)

Pizza Brid is a Brid created by @crLms1n that was added on January 19, 2026.

# Obtainment

In the house, there is a pizza box. Step on the pizza, and you will be teleported to an obby. Complete the obby and Pizza Brid will be at the end. (Be warned: This obby is not easy!)

# Trivia

- This Brid's hint reads '*In the house.*' and its description reads '*Yummy food- WAIT NO DONT EAT ITTTTTTTT*'
- This Brid is one of the first 25 Brids added to the game, being the tenth Brid.
- In this Brid's subarea, there is a button for Delta Secret Brid.
