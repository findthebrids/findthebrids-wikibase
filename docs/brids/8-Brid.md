# Overview

![8-Brid](img/8brid.png) 8-Brid is a Brid created by @kajussls121 that was added on January 25, 2026.

# Obtainment

In the Glitch realm (see entrance on its page), in the temple structure, there is a set of numbers on a panel that reads '*47 101 32 112 105 120 101 108 97 116 49 48 110*'. Decoding this ASCII text gives the code '*/e pixelat10n*'. Entering this code spawns the Brid on one of the temple's back pillars.

# Trivia

- This Brid's hint reads '*In the temple ruins.*' and its description reads '*A stray set of pixels from an old game.*'
- This Brid is one of the first 25 Brids added to the game, being the twenty-second Brid.
