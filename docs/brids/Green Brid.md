# Overview

![Green Brid](img/greenbrid.png)

Green Brid is a Brid created by @crLms1n that was added on January 18, 2026.

# Obtainment

Under a tree to the left of Farmer Brid's farm.

# Trivia

- This Brid's hint reads '*A tree.*' and its description reads '*A normal Brid that was painted green because of the trees.*'
- This Brid is one of the first 25 Brids added to the game, being the second Brid.
- This Brid's design is just a green colored version of the original Brid. This green color is actually a default MS Paint preset color.
