# Overview

![Secret Brid](img/secretbrid.png)

Secret Brid is a Brid created by @crLms1n that was added on January 19, 2026.

# Obtainment

In the Grassland house, there is a table holding a computer. On the back leg of this table, the one closest to the corner, there is a code given: '*/e secretbrid51*'. Entering this code will teleport you to this Brid's subarea.

# Trivia

- This Brid's hint reads '*Why would I tell you? (Series: Secret)*' and its description reads '*Secretive indeed.'
- This Brid is one of the first 25 Brids added to the game, being the twelfth Brid.
- This Brid's subarea contains a button for Delta Secret Brid.
- This Brid is part of the Secret series, and was the first Brid to get a series.
