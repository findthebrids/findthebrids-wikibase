# Overview

![Noclipped Brid preview](img/noclipped brid.png)

Noclipped Brid is a Brid created by @crLms1n that was added on an unknown date before July 7, 2026.

# Obtainment

In the Glitch realm, you will find a house that is partially in the floor next to the other houses. Inside, this brid is here.

# Trivia

- This Brid's hint reads '*In a house.*' and its description reads '*He got stuck in the floor.*'
- This Brid is currently the easiest obtainable Brid in the Glitch realm, being rated Hard.
