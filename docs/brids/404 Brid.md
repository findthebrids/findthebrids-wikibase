# Overview

![404 Brid](img/404brid.png) 404 Brid is a Brid created by @crLms1n that was added on January 21, 2026.

# Obtainment

In the Glitch realm (see entrance on its page), in the farthest corner from spawn, 404 Brid sits on a wall. You will have to jump pretty high for this Brid.

# Trivia

- This Brid's hint reads '*On a wall in the outskirts.*' and its description reads '*Error: File not found.*'
- This Brid is one of the first 25 Brids added to the game, being the eighteenth Brid.
- This Brid was the second of the two Brids added to the Glitch subarea before it was changed to a realm.
- This Brid used to be the hardest Brid in the game before Fatal Error was created to take its place.
