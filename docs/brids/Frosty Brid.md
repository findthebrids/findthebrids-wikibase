# Overview

![Frosty Brid](img/frostybrid.png)

Frosty Brid is a Brid created by @crLms1n that was added on January 19, 2026.

# Obtainment

In the back corner of Ice, there is a snowman. On the top of his hat there is a code given, '*/e frosty*'. Entering this code spawns the Frosty Brid in front of the snowman.

# Trivia

- This Brid's hint reads '*A jolly happy soul.*' and its description reads '*With a corncob pipe and a button nose, and two eyes made out of coal!*'
- This Brid is one of the first 25 Brids added to the game, being the eleventh Brid.
- This is the first Brid to spawn somewhere rather than teleporting the player after entering the code.
