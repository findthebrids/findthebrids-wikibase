# Overview

![Tree Brid](img/treebrid.png)

Tree Brid is a Brid created by @crLms1n that was added on January 18, 2026.

# Obtainment

In the corner of Grassland, there is an obby encapsulating a tree. Complete the obby, get on top of the tree, and obtain the Brid.

# Trivia

- This Brid's hint reads '*Up the tree.*' and its description reads '*Tre*'
- This Brid is one of the first 25 Brids added to the game, being the sixth Brid.
- On the tree this Brid resides on, there is also a low-poly mesh model of a monkey on all fours.
