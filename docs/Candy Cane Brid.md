# Overview

![Candy Cane Brid](img/candycanebrid.png) Candy Cane Brid is a Brid created by @crLms1n that was added on January 18, 2026.

# Obtainment

## Intended

On the back of the candy cane in Ice, there is morse code. Decoding it gives you the text '*/e candycane10*'. Typing in candycane10 in the code inputter teleports you to the top of the candy cane where the Brid is.

## Alternate

Wallhop up the candy cane in Ice and claim the Brid.



# Trivia

- This Brid's hint reads '*A giant sweet treat.*' and its description reads '*I don't know if I should lick this thing.*'
- This Brid is one of the first 25 Brids added to the game, being the ninth Brid.
