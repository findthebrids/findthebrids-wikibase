# Overview

![Corrupted Brid](img/corrupted brid.png) is a Brid created by @kajussls121 that was added on January 26, 2026.

# Obtainment

In the Glitch realm (see entrance on its page), there is a hole that leads under the map in a corner near spawn. Go under the map, stay on the wall, and then go up atop the diagonal platform that leads below the map to collect the Brid.

# Trivia

- This Brid's hint reads '*Find a way to get under the map..*' and its description reads '*Save file destroyed.*'
- This Brid was the first to be added to the Glitch subrealm after it had become more than just a subarea.
